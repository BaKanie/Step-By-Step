# Step-By-Step
&lt;순서대로> C언어 기반 "하루일정 점검 및 관리" 습관잡기 프로그램 (프로그래밍실습 개인 프로젝트)

## 선정 배경
직접 자동화한 구글 스프레드시트로 일정을 관리하면서,
매일 완료한 일을 점검하고 오늘 중요한 일을 강조하는 습관을 갖게 되었습니다.
이 사용 흐름을 C언어 프로그램으로 구현하고자 합니다.

## 개발 목표
- 할 일 등록·수정·삭제
- 마감 날짜·시간순 자동 정렬
- 하루 첫 실행 시 오늘의 할 일과 우선순위 선택
- 할 일별 Step 1~3 설정 및 완료 체크
- 단계별 완료 여부에 따른 별점 표시와 하루 목표 수행률 계산
- 파일 저장 및 불러오기

## 구현 계획
- 구조체 배열로 할 일 정보 관리
- 함수로 기능 분리
- 선택 정렬로 마감순 정렬
- 파일 입출력으로 기록 저장 및 복원
- 표준 시간 라이브러리 활용 방법 추가 학습

## 개발 일정
- 11주차: 입력·조회, 파일 저장·불러오기
- 12주차: 수정·삭제, 정렬, Step 완료 체크 및 중간보고
- 13주차: 오늘의 목표·우선순위, 별점·수행률 계산 및 발표 준비
- 14주차: 오류 수정, 기능 검증 및 최종보고
